# Clips for Louis's Instagram reel (Android 0.3.0)

Louis only has an iPhone, so these have to come from you. Send the raw files through Google Drive or WeTransfer (not WhatsApp: it compresses).

## Set up once
- Pair the phone with a **real** Coucou 0.5.0+ on Windows or Linux (Settings → Android phone → turn it on, scan the QR code), with real Claude Code sessions running. Not `dev-desktop.mjs`.
- Phone: vertical, native resolution, 60 fps if the recorder offers it, battery high, Do Not Disturb on, no notifications on screen, nothing personal visible.
- In the desktop's Settings → Android phone, turn on the extras you want to show (session details, the weekly recap).
- The pairing, chat and approval screens record **black** by design. Film those with a second phone or a camera.
